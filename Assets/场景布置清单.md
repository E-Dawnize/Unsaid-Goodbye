# 场景布置清单

> 基于 内容大纲.docx 流程 + StoryPhase Config + InteractionDef 整理

---

## 系统原理

- 每个交互物 = `GameObject` + `Collider2D` + `InteractableObject` 脚本 + `InteractionDef` SO
- 交互模式：`Click`(点击) / `Trigger`(进入碰撞体) / `Proximity`(进入范围后可点)
- 对话结束 → `DialogueEndedEvent` → `GameFlowManager` 匹配 RequiredBeats → 全部完成推进 Phase
- Phase 切换 → `GameFlowView` 黑屏转场 → Addressables 加载下一场景 → `ConfirmTransition`

## 每个交互物在场景中的标准挂载

```
GameObject (命名 = InteractionDef 名称)
├── Collider2D        ← 点击/触发范围
├── InteractableObject ← 挂载脚本，引用对应 InteractionDef SO
└── (可选) SpriteRenderer ← 视觉表现
```

## 特殊 GameObject
